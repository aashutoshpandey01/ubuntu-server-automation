# Ubuntu Server Automation

A collection of Zsh automation scripts for common Ubuntu Server administration tasks.

## What is this project?

This project contains practical Zsh scripts designed to automate repetitive Ubuntu Server administration tasks.

The scripts perform server health checks, service checks, disk monitoring, reporting, and backup operations.

## Why was this project created?

This project was created to practise and automate real-world Ubuntu Server administration tasks.

The goal is to reduce repetitive manual work and create reusable automation for common server administration activities.

## What scripts are included?

### `backup.zsh`

Performs automated backup operations.

### `check-disk.zsh`

Checks disk usage and helps identify potential storage problems.

### `check-nginx.zsh`

Checks the status of the Nginx web server.

### `check-ssh.zsh`

Checks the status of the SSH service.

### `server-health.zsh`

Performs an overall Ubuntu Server health check by checking important system resources and services.

### `server-report.zsh`

Generates a report containing important information about the Ubuntu Server.
